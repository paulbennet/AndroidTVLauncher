Web TV Launcher

A light home screen for Android TV and Google TV, with skins anyone can make.

Install it on your TV

  1. On the TV, open the Play Store and install Downloader (by AFTVnews).
  2. Open Downloader, type paulbennet.github.io/AndroidTVLauncher/apk and press Go. Allow Downloader to install apps when the TV asks, then pick Install.
  3. Open Web Launcher. It shows Set up this TV: pick step 1 and turn on Web Launcher home.

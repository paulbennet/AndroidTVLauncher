# Contributing

Thank you for your interest. **Issues are the only way to contribute to this project.**

- **Bug reports:** open an issue with the TV model, Android and WebView versions (Launcher settings → About), the
  skin, what you did, and what happened. `adb logcat -s WebLauncher` output helps.
- **Ideas and skin questions:** open an issue too.
- **Pull requests are not accepted** and are closed automatically. If you have a fix, describe it in an issue.
- **Skins:** you don't need this repo to share a skin. Pack it with `lx pack` and share the `.lxskin` file
  ([docs/skin-api.md](docs/skin-api.md)).
